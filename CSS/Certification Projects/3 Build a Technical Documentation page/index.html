Variables

Like many programming languages, C++ has variables which allow programmers to store data in their program.

There are many more variable types, but the four main variables are:

  • bool: A bool, or boolean, is a value that can only be true or false.
    Example: bool boolean = true;
  • string: A string is a group (or string) of written symbols or characters, and is anything between the "" symmbols.
    Example: string animal = "dog";
  • int: An int, or integer, is any whole number, and can be positive or negative
    Example: int cows = 5;
  • double: A double is any decimal number positive or negative
    Example: double cost = 5.99;
Functions

Functions in C++ are ways to simplify your code and make it easier to understand, while allowing you to stop repetitive code.

Functions have the following format:

returnType functionName(parameters){

  code to run in function here

}

returnType is the type of variable you would like to return in the function. Functions that have a return type of void do not return anything. While functions with other variable types return their respective variable. For example, a function with the return type of string will return only strings, while a function with the return type of int will only return integers.

The functionName variable is the name of the function and how it will be referenced in the code.

parameters is the variables that can be used to be given to a function to use, we can cover those later.

Example:

string name(){
 return "Jordan";
}

To reference the function in your code you do the following.

name();
Comments

Comments in C++ are ways to leave notes or comments into your code. They are ignored when you run your program and will only be noticed when looking at the code.

There are two types of comments:

  • innline comments: Comments that are only on one line
  • multi-line comments: Comments that expand to multiple lines

Examples:

// Single line comment is anything after the two slashes
/* Any text within these slashes is considered
to be a muli-line comment */
If Statements

An if statement in C++ is a way to test your code when a certain condition is true.

An if statement can be used to check if a variable is equal to a specific type, or if a variable has the same as another.
Example:

if (dog == "dog"){
  // Run code here
}
